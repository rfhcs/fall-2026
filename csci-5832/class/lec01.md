## What is NLP?

* any tech involved w/ generating, manipulating etc. with language.
    * e.g. spellcheck, dictation, etc.
* computational linguistics vs nlp
    * modeling human language using computers so we can understand how languages work.
    * less popular now due to the rise of LLMs.

### Why is NLP important?

* text data available worldwide!
* everything is digitized!
* speech recognition in less-ideal environments
* human-human interactions are now mediated by computers!
    * reddit, imessage, discord, etc.
    * THERE IS NO PRIVACY

### What is a generative model?

it allows general-purppose models to create useful outputs (text-to-text, instead of text-to-structure)

* machine translations
* dialogs
* question answering

## What are tokens?

* drives LLMs these days
* fundamental bridge

type = entries in vocab/lexicon

mention/token = instsance of type

### What is morphology?

it's the study of how words are built up

stems = core meaning-bearing units (e.g. the word "star")

affixes = change meaning/grammar ("star" + "s" = many instances of "star")

#### What is inflectional morphology?

changes the aspect of words, but not their meaning

example: walk + ing = present progressive of "walk"
