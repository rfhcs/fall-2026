# Homework 2: Language Models and Author Identification

## Notes

For the normalization process, I have chosen to strip the front matter such as table of contents, forward, pre-ambles, etc. from the text because they add nothing new to the document. I have also decided to keep case and punctuation in the normalization process. My choice for this was because sentence formulation differs between Tolkien and Doyle, and keeping those stylistic elements would improve the accuracy of my model.
